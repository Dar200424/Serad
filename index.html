About Me

I'm Sir Talha Aday Serad, a fresh graduate of Bachelor of Science in Information Technology. My programming started with academic requirements — class exercises, laboratory work and group projects — and turned into something I keep doing on my own time.

I work mostly in C# for desktop applications, Java for object-oriented practice, and HTML / CSS / JavaScript for anything that should live in a browser. I'm currently working through C++ and PHP to widen that base.

I'm not claiming seniority or years of production experience. What I do have is a habit of finishing things, documenting them honestly, and going back to improve them. That's the direction I want to keep growing in: toward becoming a Software Developer.
